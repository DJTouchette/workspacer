# Cross-language contracts

Golden fixtures that pin behaviour reimplemented in more than one language, so the
copies cannot silently drift. Each file is loaded by a test in **every** language
that owns a copy of the logic; the test asserts identical output for identical
input. If you change one implementation, the fixture forces you to change (or
consciously extend) the others.

| Fixture | Owners | Guards |
|---|---|---|
| `model-pricing-cases.json` | `apps/desktop/.../modelUsage.ts` (TS) · `services/claudemon/.../pricing.rs` (Rust) | Per-model USD rates. Longest-prefix match must price every listed id identically. |
| `deepmerge-cases.json` | `apps/desktop/.../configService.ts` (TS) · `services/hub/cmd/brain/config.go` (Go) | `deepMerge(target, source)` — the config.yaml overlay algorithm both writers use. |
| `session-schema.json` | `apps/desktop/.../shared/sessionSchema.ts` (TS) · `services/hub/cmd/brain/stores.go` (Go) | Saved-session format version. Both writers stamp it; a reader refuses a file stamped higher than its own rather than treating an unparseable shape as empty. |
| `config-lock.json` | `apps/desktop/.../lib/configLock.ts` (TS) · `services/hub/cmd/brain/configlock.go` (Go) | The advisory lock guarding config.yaml. `staleMs` and the lock filename must match — a side that expires locks sooner steals one the other still holds. |
| `host-trusted-config-cases.json` | `apps/desktop/.../lib/hostTrustedConfig.ts` (TS) · `services/hub/cmd/brain/config.go` (Go) | Config sections a bus caller may never write. Both `config.save` entry points must strip the same list — `updates.channel` reaches the updater feed URL. |
| `filename-slug-cases.json` | `apps/desktop/.../lib/fileUtils.ts` (TS) · `services/hub/cmd/brain/slug.go` (Go) | The on-disk NAME for `library.save` / `layouts.save` / `sessions.save`, which either writer may produce. Case folding is not the same operation in the two languages — `strings.ToLower` is a simple per-rune fold, `String.toLowerCase` is full Unicode special casing and can lengthen a string — so `İ` slugged to `aib` in Go and `ai-b` in TS and the item became invisible to one provider and undeletable by both. Both now fold ASCII only. |
| `path-containment-cases.json` | `apps/desktop/.../lib/pathConfinement.ts` (TS) · `services/hub/cmd/brain/fsguard.go` (Go) · `services/hub/internal/bus/policy.go` (Go) | Canonicalize-then-contain for every caller-supplied filesystem path: per-component symlink resolution (so `link/..` is not collapsed textually), the credential/config-dir second gate, and — via the `methods` block, cross-checked against `capspec.PathParam` — that every path-bearing capability actually calls the guard. Each `allow` case also carries `resolvesTo`, the path the guard must RETURN: the corpus used to pin only the verdict, and a copy that returned a textually-cleaned path instead of the resolved one passed every case in all three languages while handing back a file outside the root. The `sessionFilenames` block is a fourth copy with its own shape (`sessions.*` take a bare basename, not an absolute path), loaded by `sessionService.test.ts` and `cmd/brain/stores_test.go`. The `projectDirNames` block is a fifth (`claude.sessionsForDir` encodes a cwd into ONE `~/.claude/projects` component — `..` used to survive the encoding and climb out of it), loaded by `claudeSessionList.test.ts`, `cmd/brain/providerparity_test.go` AND `services/claudemon/src/session/transcript.rs` — that third copy is the one the other two bind themselves to by name in their comments, and it had neither the trailing-separator strip nor the refusal, disagreeing with them on 18 of 25 spellings. The `spawnCwds` block is a sixth: the one normalization a caller-supplied `agents.spawn` / `terminals.create` cwd gets, owned by `cmd/brain/profiles.go normalizeCwd` and `main/lib/spawnCwd.ts normalizeSpawnCwd` — the brain tilde-EXPANDED it (BINDING DECISION 1, on the seam that feeds `agentCwds()` into `workspaceRoots()`) while the desktop existence-checked it and silently fell back to `$HOME`. `methods` carries two normative columns: `rootSet` (which allow-list confines the caller's field) and `derivedRootSet` (the narrower list confining paths COMPOSED from it — `library.*` only). `services/claudemon` is deliberately **not** an owner OF THE CONTAINMENT CASES: `transcript.rs`'s `is_within` is documented as purely lexical, confines one hook-supplied transcript path, and exposes no `fs.*` capability, so it would fail the symlink cases by design. It IS an owner of `projectDirNames`, which is a pure string encoding and has nothing to do with that exemption. |
| `event-topic-consent-cases.json` | `services/hub/internal/capspec/eventtopics.go` (Go, the ENFORCER) · `apps/desktop/.../lib/pluginPermissions.ts` (TS, the DISCLOSER) | The event-topic registry: which pub/sub topics a non-trusted credential may receive, and on what terms (`guarded-by-capability` / `host-only` / `open-by-decision`). The hub reads its copy in `mayConsume`/`mayPublish`; the renderer reads its copy to describe a manifest's `consumes` lines in the install-consent dialog — and the renderer's copy held only the five guarded rows, so every host-only row was missing and `consumes: ["plugin.log", "sidecar.*"]` rendered at severity NORMAL. `plugin.log` is one verbatim, unredacted line of a sidecar's stdout/stderr (whose environment carries `WKS_SETTINGS` with secret plugin settings in plaintext) and `plugin.loaded` is the whole Manifest: install argv, the sidecar's server command, and every declared filesystem scope. `severityByDisposition` is normative for BOTH sides — the Go test pins it too, so host-only cannot be quietly re-declared 'normal' to make the TypeScript sweep pass. |
| `agent-error-marker-cases.json` | `services/claudemon/.../providers/mod.rs` (Rust, the WRITER) · `apps/desktop/.../main/shared/workerFailure.ts` (TS, the READER) | How a provider-side failure is spelled in a conversation. There is no structured error field on the wire: claudemon's managed-update fold turns an `AgentUpdate::Error` into an ORDINARY assistant turn prefixed `⚠️ Error: `, deliberately (the renderer only renders known item kinds and would drop a bespoke variant). That prefix is what the desktop reads to tell a worker that DIED from one that FINISHED, and the two are otherwise indistinguishable — both go idle, and the error text IS the last reply. Live consequence: an out-of-credits worker woke its Fleet Manager as "Worker finished" with the API's refusal as its summary. The fixture pins the marker and the reason each sample message must yield, including the three shapes that are NOT failures (prose that merely mentions an error, a marker that trails rather than leads, an empty message) — a reader that fired on those would relabel successful work as a crash. |
| `claude-profiles-cases.json` | `apps/desktop/.../services/claudeProfiles.ts` (TS) · `services/hub/cmd/brain/profiles.go` (Go) | The `claude.profiles.*` store. The brain listed a synthetic `default` row it never wrote (and then refused to update the id it had just listed), normalized `extraArgs`/`mcpItemIds` where the desktop returned the file verbatim, and `claude.profiles.add` on a fresh config dir minted `isDefault:true` on one provider and `false` on the other — for a method that carries `configDir`, i.e. `CLAUDE_CONFIG_DIR`. |
| `permission-request-hook-cases.json` | `services/claudemon/.../session/state.rs` (Rust) · `apps/desktop/.../sessionStore/hookEventRouter.ts` (TS) | The `PermissionRequest` hook frame — the thing that turns a Claude Code permission prompt into an ANSWERABLE record. Two readers pick DIFFERENT fields off the same payload: claudemon reads `tool_name` + `summary`\|`message` and is the ONLY thing that can put a PTY session into `SessionMode::Approval`; the desktop reads `tool_name` + `tool_input` + `permission_suggestions` to render the card the user clicks. A CLI rename of either set breaks exactly one side, and the failure mode is invisible — a prompt the CLI is blocked on with nothing to approve. `registerable` is normative too, and is the field that was wrong: `HookEventKind::REGISTERABLE` filed `PermissionRequest` as "internal / forward-compat only", so `claudemon init` never wrote the hook into `~/.claude/settings.json` and a PTY agent's permission prompt produced no record at all — an unresolvable block, killable but not answerable. Loaded by `state.rs::permission_request_contract_cases` and `permissionRequestContract.test.ts`. |
| `claude-model-catalog-cases.json` | `apps/desktop/.../services/claudeModels.ts` (TS) · `services/hub/cmd/brain/models.go` (Go) | The `claude.listModels` reply. A CATALOG method: the brain answers it for every web/mobile/remote/MCP client while the desktop serves its own IPC copy, and the two returned a different contract — four alias rows vs six (so the 1M-context `opus[1m]`/`sonnet[1m]` ids were unreachable from the web picker), `Opus — latest` vs a version-stamped `Opus 4.5`, no `context` badge and no `defaultPermissionMode` on one side, and `<synthetic>` offered as a selectable model. |
| `provider-parity-cases.json` | `apps/desktop/.../lib/providerParity.ts` (TS, + its call sites in `libraryService`/`layoutService`/`sessionService`/`fileService`/`claudeSessionList`/`hubCapabilities`) · `services/hub/cmd/brain` (Go: `stores.go`, `library.go`, `fsops.go`, `discovery.go`) | The non-path half of "the same bus call must give the same answer whichever provider ran": list ORDER and scalar coercion. Go sorts strings by raw bytes and the desktop used `localeCompare`, so `library.list`, `fs.listDir` and `fs.listEntries` came back in stably different orders. Worse, `localeCompare` is a METHOD: a store row whose YAML scalar is not a string (`createdAt: 5`, or an unquoted ISO date — js-yaml 4 parses that to a Date) threw inside the comparator, and the function-level catch turned the throw into an EMPTY LIST, so `layouts.list` and `sessions.list` lost every well-formed row while the brain listed them all. The `suffix` block pins `TrimSuffix` against `String#replace`, which removes the first occurrence ANYWHERE — `.jsonlagent-x.jsonl` became `agent-x.jsonl`, matched the subagent filter, and dropped a row one provider listed. Loaded by `providerParity.test.ts` and `cmd/brain/parity_ordering_test.go`. |

Rates are USD per **million** tokens. Add a case whenever a new model id or merge
edge case ships; the cheapest place to catch drift is here, before it becomes a
mispriced session or a clobbered config.
