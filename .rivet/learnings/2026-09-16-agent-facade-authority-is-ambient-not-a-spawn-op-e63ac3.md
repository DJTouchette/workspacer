# Agent facade authority is ambient, not a spawn option

## Observation
Once Workspacer authenticates a supported spawned agent, the desktop and headless spawn choke points must always mint an operator facade token. Legacy mcpFacade/toolScope/pluginTools and token profile/yolo grant fields may parse, but must not narrow tool registration, profiles, permission modes, or recursive child spawns. Library MCP entries must be merged into the same session config because a second --mcp-config replaces the first.
