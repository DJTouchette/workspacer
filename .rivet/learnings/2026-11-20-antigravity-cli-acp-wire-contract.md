# Antigravity CLI ACP wire contract and binary-stem mapping

## Observation
Verified live against Antigravity ACP Server 1.5.13 (`agy.exe acp`):

- **Provider ID vs binary name**: Provider ID `"antigravity"` maps to executable stem `"agy"` (not `"antigravity"`). Binary resolution in `services/claudemon/src/daemon/spawn.rs` (`provider_binary_stem`), `services/hub-rs/src/services/models.rs` (`binary_name`), `services/hub-rs/src/services/provider_utilities/tools.rs`, and `services/hub-rs/src/services/provider_utilities/completion.rs` must translate `"antigravity" -> "agy"` while still honoring `WKS_ANTIGRAVITY_BIN` / `agents.binaries.antigravity`.
- **ACP `session/new` models and thinking effort**: `configOptions` exposes base model families (`id: "model"`) and dynamic per-model `thought_level` options (`id: "thought_level"`), while `models.availableModels` lists compound `<model>-<effort>` IDs (e.g. `gemini-4-neon-xhigh`). Joining both in `parse_acp_models` populates accurate per-model `ModelInfo.effort_levels` in a single `session/new` round-trip.
- **ACP capabilities & Workspacer integration**: `session/new` accepts HTTP `mcpServers` and `_meta.antigravity.systemPrompt.append` for Workspacer facade tools and role instructions; `promptCapabilities.image: true` accepts inline base64 image blocks (`ImageUse::Inline` in `SessionStore::image_use`).
- **Resume replay**: `session/load` replays prior turns via `user_message_chunk` and already-completed `tool_call` notifications (with `status: "completed"` and `rawOutput` directly on `tool_call`). The adapter persists `workspacer_session_id -> acp_session_id` under `~/.workspacer/antigravity-sessions/` and suppresses duplicate replay writes when `ConversationStore::has_conversation` is already true.
- **Permissions & usage**: `session/request_permission` provides `options` with `allow_once`, `allow_always`, `reject_once`, `reject_always` kinds (mapping `allow_always` to Workspacer `always_options`). `session/update` `usage_update {used, size}` provides real paired context occupancy and context window size, while `session/prompt` response `usage` reports per-turn `inputTokens`, `outputTokens`, `cachedReadTokens`, and `thoughtTokens`.
- **Slash commands, titles & `/compact`**: `available_commands_update` advertises slash commands `{availableCommands: [{name, description}]}` (invoked with `/name`), and `session_info_update` advertises auto-generated titles `{title}`. Sending `"/compact"` (or `"/compact <instructions>"`) as `session/prompt` after at least one prior turn is intercepted natively by `agy acp` as a real compaction (no assistant text emitted, updated `usage_update` + `stopReason: "end_turn"`).
- **PascalCase built-in tool inputs**: Antigravity CLI built-in tools use PascalCase argument keys (`run_command`: `CommandLine` + `toolSummary`; `read_file`: `Path` + `StartLine`/`EndLine`; `edit_file`: `Path` + `Target` + `Replacement`; `write_file`: `Path` + `Content`; `invoke_subagent`: `Role` + `Prompt` + `TypeName`). Native tool preview, diff/changed-files, file-viewer line jump, and child-agent detection must accept these alongside Claude/Codex keys.
- **On-disk usage**: `~/.gemini/antigravity-cli/brain/<uuid>/.system_generated/logs/transcript.jsonl` records exact per-request `model`, `input_tokens`, `cache_read_tokens`, `output_tokens`, and `created_at` on `PLANNER_RESPONSE` lines (pure JSONL, no SQLite locking). Quota window percentages/resets are not exposed locally or over ACP and must be reported as `Measured::Unavailable`.
- **Subagents & background shell tasks**: `agy acp` does not emit separate subagent progress or background-task JSON-RPC notifications (only `tool_call` / `tool_call_update` for `invoke_subagent`). However, the parent's `brain/<acp_sid>/.system_generated/logs/transcript.jsonl` records every spawned subagent's `conversationId`, every backgrounded `run_command`'s `task-<N>` (with live log at `brain/<acp_sid>/.system_generated/tasks/task-<N>.log`), and completion `<SYSTEM_MESSAGE>` wakes (`sender=<child_uuid>` or `sender=<acp_sid>/task-<N>`). Each child subagent writes its own full transcript to `brain/<child_uuid>/.system_generated/logs/transcript.jsonl` (with `tool_calls[].args` values JSON-encoded as strings).
- **Workspacer skills & MCP facade**: `agy acp` natively connects to Workspacer's HTTP MCP facade (`mcpServers: [{name: "workspacer", type: "http", url: "http://127.0.0.1:<port>/mcp?t=<token>", headers: []}]`, calling `initialize` + `tools/list`), and `agy acp --add-dir <wrapper>` natively loads skills declared via `<wrapper>/.agents/skills.json` (`{ "entries": [{ "path": "..." }] }`), surfacing Workspacer role skills (`spawn-agent`, `checkpoint`, `handoff`, etc.) directly in both Antigravity's skill registry and `available_commands_update`.
