# MCP migration evidence

The Go MCP source remains an independent behavior reference while the Rust
facade supplies actual transport, authentication, schemas and composition.
See `reviews/mcp.json` for already recorded slices and the additional review
plan generated by the remaining-facade audit. A catalog match proves schema
coverage, not tool execution parity.

`assets/mcp-tools.json` and `assets/mcp-help.json` remain the unmodified Go
capture; the optional `make hub-mcp-catalog` reference command regenerates those
inputs. Rust-specific descriptions live in the authored
`assets/mcp-rust-presentation.json` overlay, applied by `mcp/presentation.rs`.
This lets standalone/embedded Rust workflow, task-reference, result-schema and
template availability be described accurately without rewriting the original
reference or changing parameter constraints. Overlay tests require each old
phrase to exist and prove every non-description catalog value is unchanged.
Status-summary guidance deliberately still requires the provider that implements
`agents.summarizeStatus`; migrating workflows does not manufacture that provider.

The remaining-facade audit adds actual HTTP/broker regressions in
`tests/mcp/parity.rs`, transport-specific preference checks in
`tests/mcp/sse_preferences.rs`, and independent config guards in
`mcp/config_save.rs`. The old data-loss guard was two layers: advertised object
schemas plus a local wholesale-map check independent of the MCP SDK. Both are
now retained. Empty task-reference coordinates are refused before provider
calls. Legacy JSON-string spawn IDs support first-message delivery, and a bare
model override omits an unavailable canonical context window.

Existing Rust behavior deliberately improves uncertain-delivery handling:
`messageQueued:false` is an unconfirmed receipt, not permission to send the
prompt again. Spawn errors retain the receipt and prohibit blind replay.
Task-reference CAS conflicts remain ordinary domain data rather than transport
failures. Modern discovery/list cache hints remain `ttlMs:0` and private.
