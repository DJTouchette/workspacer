#run it without you

Hand the fleet to another agent, or check on it from your phone. Neither one needs the desktop app open.

supervise

Put an agent in charge

  • Ask the fleet. Type a question and it becomes a supervisor — a Claude with the work{spacer} tools attached that can see and drive every other agent.
  • Preset sweeps for the boring parts: Standup, Triage, Audit, Cost.
  • Two machines, one fleet. Federate your desktop's hub with your laptop's and every client — desktop, web, phone, terminal — shows both machines' agents side by side, approvals routed to the right box, offline peers tombstoned instead of vanished.
  • Jobs that run without you. Recurring or one-off: spawn an agent with a prompt, run a command, or call a capability — on a timer, at a time of day, or once. A job can run a script first and hand the output to the agent, and skip waking a model at all when the script finds nothing. The hub owns them, so they keep firing with the app closed. Docs →
  • The whole fleet over MCP. List agents, read transcripts, spawn, prompt, approve, answer, even navigate the app — any MCP client can run the place, and every agent you spawn can get the tools at a scoped tier (observe-only up to full control). Plugins can contribute tools of their own.
remote

Check on it from anywhere

  • A phone PWA at /m you install from a QR code — reads as a Fleet Manager: Fleet, Waiting, Flows, Briefs and Dispatch tabs, with big approve buttons for clearing approvals from the couch.
  • The full app over the bus, the real renderer at /app, with tmux-style layout mirroring between desktop and web.
  • No desktop required. workspacer serve runs the same fleet on a headless box. Sharing is off by default, and tokens can be scoped view-only.
#one quiet daemon, one bus, every client

The desktop app spawns and supervises the daemons. Sessions live in the daemon, so closing a window never kills an agent.

desktop client

Electron + React

The primary GUI. Spawns the daemons, renders the panes, forwards events to every client.

session daemon

claudemon [rust]

Owns the sessions and PTYs, runs the per-provider adapters, streams conversation and usage.

control plane

hub [go]

The event bus, supervisor, capability router, plugin system, and MCP facade.

Every client — desktop, web, phone, and the Rust TUI — talks to the same bus, so they never disagree about what the fleet is doing. Read the internals →
